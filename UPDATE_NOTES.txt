CineCalendar 3.9.8 finalizează remedierea problemelor rămase după 3.9.7.

Recomandări:
- elimină complet excluderea globală și penalizarea specială pentru Romance;
- genurile sunt tratate normal de profilul personal și de ratingurile utilizatorului;
- opțiunea veche „Exclude Romance” a fost eliminată din Setări.

„Ce văd acum?”:
- „Aleg filmul ăsta” fixează acum efectiv alegerea pentru ziua curentă;
- filmul ales rămâne afișat după schimbarea paginii sau repornirea aplicației;
- alegerea se eliberează când utilizatorul cere alt film, îl marchează văzut sau începe o zi nouă.

Postere:
- încărcarea posterelor folosește o coadă centrală;
- maximum 6 descărcări rulează simultan;
- cererile duplicate pentru același poster sunt reunite într-o singură descărcare;
- cache-ul existent este folosit imediat, iar imaginile invalide sunt eliminate.

Release / stabilitate:
- verificarea live a profilului public IMDb este acum un gate obligatoriu, cu până la 3 încercări;
- un build Stable nu mai poate fi publicat dacă sincronizarea live IMDb este stricată;
- actions/upload-artifact este actualizat la v7 / Node 24;
- textul din Setări descrie corect updaterul Stable activ și sursele reale de metadata.

Toate remediile au teste de regresie dedicate.
